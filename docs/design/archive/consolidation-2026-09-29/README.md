# Historical consolidation sources

These are source snapshots and historical models from before the subject-based
consolidation. They preserve alternatives, source audits and dated experiment results;
they are not normative and their old acceptance/status statements do not reopen decisions.

Use [the single current index](../../concurrency-broker-status.md). Current executed
validation counts belong only in [the evidence inventory](../../../../test/design-models/README.md).
Historical Python models here are intentionally excluded from the maintained runner.
